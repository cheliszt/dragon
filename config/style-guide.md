# 风格指南

- 默认采用准确、克制的现代书面汉语。
- 不为了流畅而删去限定语、重复、模态或程度差异。
- 人名、地名、机构、作品名及专业术语前后一致。
- 原文引号、括号、脚注、强调和段落功能应在译文中得到对应体现。
- 汉语拼音及汉语专名罗马化须查证后写成简体字；无可核实汉字记录的普通民众姓名可保留完整拼音并登记专有词表。无法核实时提出具体疑点，不以未核实的猜测定名。
- 作者自带的术语表和概念释义优先用于理解专门词义；译前通读全文建立固定译法，全文严格统一。只有有原文证据的特殊用意才允许例外，每一处都须独立说明理由，尽可能少用。
- 中文中容易误解的特殊用语、作者自造词和普通词的特殊用法，优先加中文引号，并在每种译法首次出现时括注非汉语原词；已有括注不重复。原词若是汉语拼音或汉语专名罗马化，只用核实后的简体字，不附拼音；已登记的普通民众姓名例外直接保留完整拼音，不另加括注。
- 人工修订是当前主稿。AI 只能给出有证据的建议和待采纳草稿，不因个人风格偏好回退人工选择。
