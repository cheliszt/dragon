# 翻译工作规程

1. 只翻译由批准源文生成的当前翻译单元，不增删源文事实。翻译单元可跨原始块与 PDF 页，原始块仅用于追溯。
2. 译文必须完整传达人物、实体、动作、否定、条件、因果、程度、时间与数字。
3. 不猜补无法确认的 OCR 内容；将疑问写入 `source_questions`。
4. 数字、单位、公式、版本号、脚注号与交叉引用必须保留并逐项对应。
   - `numeric` 类问题一律降为最低级 `note`（提示），不列入警告或阻断项，不因这类提示中止、回退翻译或阻止交付。
   - 标题前的 `1`、`1.1`、`2.3` 等属于章节编号，不是数量或计量单位；不得把其后的 Radio、Introduction、Revisiting 等标题词识别为单位。编号的等价排版或中文写法不构成警告。
   - `1940s`、`1940’s` 表示年代，末尾 `s` 不是“秒”。译为“1940年代”“20世纪40年代”或“二十世纪四十年代”等语义等价表述时，不产生数值警告或提示。确有依据的年代错译仍可作为最低级提示保留。
5. 标题、列表、表格、引文、图注和代码应保持原有 Markdown 结构。
6. 同一翻译单元内的跨页续句应整体理解、完整翻译，并按目标语言自然调整语序；不得因原始块或页码边界强行断句。不得挪用其他翻译单元的内容，不得重复翻译或凭空补写。
7. 新术语或存在歧义的译法写入 `translator_notes`，不得静默改写术语基线。
   - 正式翻译前必须通读全部批准原文，寻找作者反复使用的关键概念、专用概念和明确定义的术语，引用原文依据及位置，为每个概念确定一个固定译法，保存术语基线后再翻译。
   - 全文检索后可规定标准译法、源词变体和不再采用的译法，预览受影响段落并批量应用；人工规定优先，其他人工修订必须保留。
   - 术语原则上一词一译，不为避免重复而换词。特殊用意的例外必须逐次提供原文依据和理由，显示在对应段落审阅中，并尽可能少用。不得以笼统的“语境不同”免除说明。
8. 译文使用任务所选目标语言（简体中文或英语），自然、准确，适合学术阅读。已有目标语言及未选源语言原样保留。
9. 简体中文与繁体中文分别处理。用户所选中文源语言包含汉语拼音，也可单独选择拼音。拼音须依拼写和汉语上下文推定，不把英文词或其他拉丁字母文字无依据地当成拼音。
10. 目标为简体中文时，正文、脚注及文末参考文献中的汉语拼音均查证后转为简体字，不在后面括注拼音。汉语地名须使用现实地名并列入专有词表；人名须检索确认汉字，简称对应同一人的全名。没有可核实汉字记录的普通民众姓名可保留完整原文拼音，并在专有词表注明人物身份、原文位置和待核依据；这一例外不适用于地名、作者、广播从业者和机构人员。除该例外外，译文不得保留拼音。证据不足时记录待核疑点，禁止仅按读音猜造汉字。目标为英语时，先理解拼音的汉语含义再翻译。
